# 전처리·토큰화 안내 (팀 공유용)

수집·통합된 언론사 뉴스를 분석에 넣기 전, **구조 정제(전처리)** 와 **토큰화** 두 단계로 가공함. 이 문서는 각 단계가 무엇을 하고 어떤 파일·컬럼이 나오는지 정리한 것.

분석 대상 — 2026.05.05~05.11, 9개 언론사 / 4개 매체그룹(경제 · 통신·보도 · 정치색 · 지상파)

---

## 전체 흐름

```
통합_본문_bs4_언론사_{기간}.csv      (수집·통합 결과)
        │  ① 전처리  (언론사_네이버뉴스_전처리_colab.ipynb)
        ▼
전처리_본문_언론사_{기간}.csv        (가독 본문 + 메타 + 플래그)
        │  ② 토큰화  (언론사_네이버뉴스_분석토큰화_colab.ipynb)
        ▼
분석토큰_언론사_{기간}.csv           (분석용 tokens)
```

> 참고용 행수 — 2026-05-29 재실행 기준 `12,122 → 11,990 → 11,990` (1차 5/24 기준은 `14,169 → 14,057 → 14,057`). 재수집·재실행 때마다 행수가 달라지므로 정확한 수치는 산출 CSV·`분석_진행상황.md` 참고

- 모든 파일은 `data/news/` 폴더
- 통합본·전처리본은 **읽기 전용** — 덮어쓰지 않고 항상 새 파일로 저장
- 정제 원칙은 **보수적** — 기사 본문을 잘못 지우는 게 가장 위험하므로, 애매하면 안 지우고 원본을 남김. 덜 지운 군더더기는 ②토큰화에서 불용어로 거름

---

## ① 전처리 — `언론사_네이버뉴스_전처리_colab.ipynb`

입력 `통합_본문_bs4_언론사_{기간}.csv` → 출력 `전처리_본문_언론사_{기간}.csv`

### 하는 일
1. **메타 정리** — `media_group`·`press` 정리, `category`(예 `스포츠/kbaseball`)에서 `/` 뒤를 떼어 상위분류 `article_category`(→`스포츠`) 생성(원본은 `article_category_full`에 보존), 날짜만 뽑은 `date` 추가
2. **본문 정제 `clean_body`** — 원본 `body`는 그대로 두고, 정제본 `body_cleaned`를 따로 만듦. "기사 본문이 아닌 부분"만 정해진 위치·형태에서 제거 →
   - 방송 화자 표시 `<앵커>`·`[앵커]`·`[기자]`·`[리포트]`
   - 방송 코너·지국 이름표 `[KBS 강릉]`·`[뉴스25]`·`[정치쇼]`
   - YTN 라디오 머리말(방송일시·**방송시각**·진행자), MBC 뉴스외전 머리말
   - 연합뉴스·뉴스1·뉴시스 기사 머리 `(서울=연합뉴스) ○○ 기자 =`
   - 사진·자료 출처 `[사진 출처=뉴스1]`·`(사진=…)`·`사진=연합뉴스`
   - 기사 맨 끝 기자 이름·이메일 `이미아 기자 mia@hankyung.com`
   - 매체별 맨 끝 제보·저작권 안내(KBS `■ 제보하기`·MBC·YTN·SBS Biz·한국경제 자동생성 안내문)
   - 저작권 블록 `<저작권자 ⓒ …>`
   - 기사 맨 끝 제작진 표기 `영상편집:홍길동 그래픽:김철수`
   - 장식기호 `◆◇▲■◎` 등
   - **보존(안 지움)** — 발언 인용 `[트럼프/미국 대통령 : …]`, 본문 속 메일 `info@PGSA.ir`, `<장자(莊子)>`, 숫자·`%`·㎞·영문약어(AI·HMM)·한자(美·韓)
3. **정제본·합본 컬럼** — `title_cleaned`(제목 공백+유니코드 정규화만), `body_cleaned`(위 정제), `text`(=`title_cleaned`+`body_cleaned`, 토큰화 입력), `body_length`(정제본 글자 수)
4. **플래그(지우지 않고 표시만)**
   - `is_weather` — `[날씨]` 단신
   - `is_closing` — 클로징/뉴스 마칩니다
   - `is_within_press_dup` — 같은 매체·같은 날·같은 제목이 2건 이상(반복 송고 추정)
   - `is_cross_press_dup` — 같은 날·같은 제목이 2개 이상 매체에 걸침(연합뉴스 등 재전송 추정)
   - 여러 매체가 같은 사건을 다룬 건 의제 비교에 의미가 있어 지우지 않고 표시만 함 → 분석 때 필요하면 골라 제외
5. **실제로 행을 삭제하는 경우는 둘뿐** — 분석 기간(05-05~05-11) 밖 / 정제 후 본문 20자 미만(사진만 있던 단신 등)

> 참고 — 원본과 똑같은 `body_cleaned`가 약 37%인데, 그 기사들은 애초에 뗄 군더더기가 없어서임(예: 조선일보·한겨레는 정형 푸터가 적음). KBS는 전부 `■ 제보하기` 푸터가 있어 거의 다 바뀜

### 전처리본 컬럼
| 컬럼 | 뜻 |
|---|---|
| `article_id` | 기사 고유 번호(매체그룹→매체→발행시각 순 정렬 후 부여) |
| `link` `pubdate` `date` | 원문 링크 / 발행시각 / 날짜 |
| `category` | 원본 네이버 섹션값 |
| `article_category` | 상위분류(`/` 뒤 제거), 결측은 `미분류` |
| `article_category_full` | 원본 category 보존 |
| `press` `media_group` | 개별 언론사 / 4개 매체그룹 |
| `source_period` `source_file` | 출처 기간 / 출처 수집 파일명 |
| `title` `body` | **원본** 제목 / 본문 |
| `title_cleaned` `body_cleaned` | **정제** 제목(정규화만) / 본문(군더더기 제거) |
| `text` | `title_cleaned` + `body_cleaned` (토큰화 입력) |
| `body_length` | 정제 본문 글자 수 |
| `is_weather` `is_closing` `is_within_press_dup` `is_cross_press_dup` | 표시용 플래그(위 4번) |

## ② 토큰화 — `언론사_네이버뉴스_분석토큰화_colab.ipynb`

입력 `전처리_본문_언론사_{기간}.csv`의 `text` → 출력 `분석토큰_언론사_{기간}.csv`. LDA·빈도·워드클라우드의 입력이 됨

### 하는 일
1. **가벼운 전처리** — HTML 엔티티 복원(`html.unescape`), 이모지 제거
2. **Kiwi 형태소 분석** — 한글에 강한 형태소 분석기 Kiwi 사용. 한글만 남기는 방식(`hangeul_only`)은 **안 씀** → `AI`·`HMM`·`美`·`韓` 같은 의제어가 사라지므로
3. **명사류만 선별** — 품사가 명사(NNG)·고유명사(NNP)·영문(SL)·한자(SH)이고, 길이 2자 이상, 불용어가 아닌 토큰만 남김
4. **불용어** — 뉴스 상투어(`기자`·`연합뉴스`·`오늘`·`이날`·`사진`·`영상편집`·`이데일리`·`포토` 등) + **매체명**(`KBS`·`MBC`·`SBS`·`YTN`·`라디오`) 제거. 매체명을 빼는 이유 — 같은 의제를 다룰 때 그룹별 특화어를 뽑아 보면 매체 이름 자체가 상위로 떠 분석을 흐림(예: 지상파 그룹의 특화어 1위가 `KBS`라면 정보 가치 0). 노트북 상단 `NEWS_STOP`에서 관리하며 계속 보강 가능
5. **핵심 의제어 보존 `keep_terms`** — `AI`·`HMM`·`ETF`·`美`·`韓`·`호르무즈`·주요 인물명(장동혁·박민식 등)을 사용자 사전에 등록해 분해·삭제 방지. 노트북 상단 `KEEP_TERMS` 에서 관리(주간 갱신)
6. **다어절 고유명사 결합** — Kiwi가 `EMK 뮤지컬 컴퍼니`처럼 공백 든 고유명사를 한 토큰으로 주면, 내부 공백을 `_`로 바꿔 한 토큰으로 보존(`EMK_뮤지컬_컴퍼니`)
7. **저장** — `tokens`(공백으로 이어붙인 토큰), `n_tokens`(토큰 수)

### 분석토큰 컬럼
`article_id` · `press` · `media_group` · `date` · `article_category` · `title_cleaned` · `n_tokens` · `tokens`

- `tokens` 예시 — `한동훈 단일 장동혁 제명 인사 연대 부산 박민식 공천 韓 …`
- 매체그룹별 평균 토큰 수 — 1차(2026-05-24) 기준 정치색 211 / 통신·보도 196 / 경제 172 / 지상파 123(방송 대본이라 짧음). 재실행(2026-05-29) 기준 통신·보도 평균이 122 정도로 감소 — LPOD 트랙 재수집으로 전사체 비중 변화

### 분석에서 쓰는 법
```python
import pandas as pd
df = pd.read_csv('data/news/분석토큰_언론사_260505_260511.csv', encoding='utf-8-sig')
df['tokens_list'] = df['tokens'].fillna('').str.split()   # 토큰 리스트 복원
# 비기사·재전송을 빼려면 전처리본의 플래그를 article_id로 붙여서 거름
pre = pd.read_csv('data/news/전처리_본문_언론사_260505_260511.csv', encoding='utf-8-sig',
                  usecols=['article_id','is_weather','is_closing','is_within_press_dup','is_cross_press_dup'])
df = df.merge(pre, on='article_id', how='left')
sub = df[~df['is_within_press_dup']]
```
- 플래그(`is_weather`·`is_closing`·`is_within_press_dup`·`is_cross_press_dup`)는 **전처리본**에 있음(분석토큰 파일엔 없음 → article_id로 join 필수)

## 한계·주의
- 정제는 보수적이라 일부 군더더기(매체별 제작진 표기 변형, 본문 중간 사진캡션 등)가 남을 수 있음 → 대부분 ②토큰화 불용어로 흡수, 필요시 `NEWS_STOP` 보강
- 일부 인물명이 분해될 수 있음(예 헤드라인의 약식 표기) → 토큰화 노트북 상단 `KEEP_TERMS`에 인명 추가하면 보존(주간 갱신 항목)
- `is_within/cross_press_dup`은 "같은 날짜+정규화 제목" 기준이라, 자정 경계(어제 23시 vs 오늘 0시)나 반복형 제목(클로징 등)은 부정확할 수 있음 → 삭제가 아닌 표시라 분석 때 참고용
- 불용어·핵심어 목록은 1차 LDA 결과를 보고 계속 보강하는 게 정상
