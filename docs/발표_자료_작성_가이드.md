## 한계·caveat (꼭 한 슬라이드 차지)

발표 자료에 빠지면 안 되는 솔직한 한계 — 그대로 인용 가능:

1. **표본 — 한 주치(7일)**
   - 한 주 안의 특정 사건(예 6·3 지방선거, 호르무즈 사건)이 결과를 크게 흔드는 구조
   - 장기 패턴이 아니라 **그 주의 스냅샷**임을 명시

2. **매체 표본 — 9개**
   - 각 그룹 2~3개 매체에 의존 — 그룹 대표성은 제한적
   - 특히 통신·보도(연합뉴스·YTN) 2개로 그룹 평균이 흔들릴 여지

3. **본문 길이 효과**
   - YTN은 라디오 전사체가 많아 본문이 김 → 토픽 비중 측정에 길이 영향
   - 발표 시 "통신·보도의 국제 우위는 일부 YTN 길이 효과" 언급 필요

4. **dedup 효과**
   - 지상파는 같은 사건을 여러 매체가 거의 동일하게 송고 → 중복 제거로 약 39% 잘림
   - **그룹 내 비율 해석은 OK, 절대 volume 비교는 주의**

5. **소프트뉴스 처리**
   - 스포츠·연예 카테고리는 우주에서 빼고 분석 — 1차에선 통신·보도가 0%(잔존 우주에 카테고리 없음)였으나 재실행에선 LPOD 트랙 재수집으로 정상화됨

6. **감성 사전(KNU) 한계**
   - 일반 감성 사전이라 뉴스 특유 표현(예 "철회 압박", "전망 어두워") 일부 미반영
   - 따라서 **그룹 간 절대값 비교**보다 **동일 의제 내 비교**가 더 신뢰성 있음

7. **본문 수집 누락 ≠ 결함**
   - BS4 자동 수집 실패 29건 = 분석 우주의 0.32%
   - **전수 검수 결과 전부 본문 부재 콘텐츠**(표·카툰·속보단신) — 데이터 누락이 아닌 콘텐츠 자체가 그림·표 위주
   - 발표에서 "데이터 누락 가능성 없냐" 질문 나오면 이 슬라이드(#5)로 받음
