## 0. HARD CONSTRAINT (scope clarified in v3) **[R2-fix]**

## 1. ALTITUDE — THIN conversion (changed in v2) **[R1-fix]**
Round-1 (subagent C + codex C) showed that re-architecting cells into `def main(cfg)` risks breaking byte-identity via (a) closures/default-args captured at def-time (e.g. fulltext `calculate_score(..., ds=df_senti)`), (b) `os.chdir(PROJECT_DIR)` side-effects, (c) statement-scope changes. Therefore:
- **Method = literal `jupyter nbconvert --to script` per notebook, then patch ONLY the path-definition lines** to read from `config.py`. Keep every statement at the exact same module-level scope and order the notebook ran them.
- **Lines to strip/neutralize (output-neutral) — expanded in v3 [R2-fix]:** `%magics` AND nbconvert's rewritten `get_ipython().run_line_magic(...)` / `get_ipython().system(...)` forms; `!shell` escapes — specifically **LDA cell 0 `! pip install gensim wordcloud matplotlib pyLDAvis`** (codex B: nbconvert turns this into a `get_ipython().system` call that breaks plain `python`); `display()`; tqdm bars. **`plt.show()` caveat [R3-fix]:** in fulltext/absa, `plt.savefig(...); plt.show()` share ONE `;`-joined physical line — a line-delete would also drop the savefig (a PNG). So do NOT line-delete it; either split on `;` keeping savefig, or simply leave `plt.show()` (harmless no-op under the Agg backend). None affect saved DATA outputs. Verify by diffing the converted script's non-stripped lines against the cell source.
- The two stage-4 files are ALREADY `.py`; do not rewrite — only patch their path lines (`BASE_DIR`, `DATA_PATH`, `OUT_DIR`, `DL_OUT`) to config.
- `run_all.py` runs each module **strictly as an external OS subprocess** (`subprocess.run([sys.executable, module_path])`), NOT in-process `runpy`/import — this isolates `os.chdir`/globals so orchestrated == standalone. **[R2-fix: external subprocess only, no in-process runpy]**
